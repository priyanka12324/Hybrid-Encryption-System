HES-CQCT chat

Messages are encrypted in your browser with the three-layer cipher before they leave this device. The server only relays ciphertext. Both devices must enter the same three keys. Use demo keys, never real passwords.

Circular queue on the server

Each node holds one ciphertext and its nonce. The rear always links back to the front. When the ring is full, the oldest node is dequeued to make room.
